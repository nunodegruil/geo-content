# Sistema de Conteúdos Georreferenciados

Projeto Final de Licenciatura em Engenharia Informática.

## Descrição

Plataforma web para criação e visualização de conteúdos georreferenciados com base em localização.

## Estrutura do Projeto

geo-content/
- backend/
- frontend/
- database/
- docs/

## Tecnologias previstas

- Frontend: React + TypeScript
- Backend: Node.js + Express + TypeScript
- Base de Dados: PostgreSQL + PostGIS
- Mapas: Leaflet
